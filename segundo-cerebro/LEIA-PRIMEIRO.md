# Segundo Cérebro · Klaus Labs

Presente de comemoração dos 100 membros da comunidade gratuita Klaus Labs.

## O que é

Uma pasta de arquivos de texto que vira a memória do seu agente de IA. Ele lê no começo de toda conversa e atualiza no fim. Resultado: ele para de esquecer quem você é, o que seu negócio faz e onde vocês pararam.

## O que tem aqui

| Arquivo | Para quê |
|---|---|
| `Segundo-Cerebro-Guia.pdf` | O guia completo: o que é, como funciona, como instalar em cada ferramenta, rotina e exemplos |
| `COMO-INSTALAR.md` | Passo a passo por ferramenta (OpenBot, Hermes, Claude Code, Codex, Cursor, ChatGPT, Claude.ai, Gemini) |
| `segundo-cerebro/SKILL.md` | A skill: monta, abre, salva e faz faxina no cérebro |
| `modelo/` | O cérebro pronto para copiar e preencher (troque o que está entre [colchetes]) |
| `versoes/instrucoes-navegador.md` | Texto para colar no Projeto do ChatGPT, do Claude.ai ou num Gem |

## Jeito mais rápido (sem baixar nada)

Mande para o seu agente (OpenBot, Hermes, Claude Code):

> Instale como skill o arquivo deste link: https://raw.githubusercontent.com/dilandia/klaus-labs/main/segundo-cerebro/segundo-cerebro/SKILL.md

Depois: **"monta meu segundo cérebro"**.

## Três frases para decorar

- **"monta meu segundo cérebro"** (uma vez)
- **"abre meu cérebro"** (começo da conversa)
- **"salva"** (fim da conversa)

Dúvidas: comunidade gratuita Klaus Labs, klauslabs.com.br/grupo

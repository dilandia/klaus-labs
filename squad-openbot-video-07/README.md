# Squad de marketing no OpenBot

**Um time de 5 agentes que cuida do Instagram, montado por um agente coordenador.**

Na aula, o agente **Maestro** recebe um blueprint e cria sozinho o canal, as skills e os 5 agentes do time:

| Agente | O que faz |
|---|---|
| Estrategista (líder) | Escolhe o post, escreve o briefing e distribui o trabalho |
| Redator | Escreve a legenda, o texto alternativo e a chamada |
| Diretor de Arte | Cria a imagem do post |
| Revisor de Marca | Confere texto e imagem contra a marca antes de você aprovar |
| Publicador | Publica no Instagram, só depois do seu "aprovado" |

Atenção: este é o material exatamente como aparece na aula, configurado para o Instagram da Klaus Labs (pastas, marca e perfil). Para usar na sua marca, troque esses dados antes de mandar para o Maestro.

Aula completa: https://youtu.be/22dHRokZLxo

## Ordem de uso
1. **[01-COLAR-NO-MAESTRO.txt](01-COLAR-NO-MAESTRO.txt)**: cole nas instruções do agente Maestro. Cabe no limite de 2.000 caracteres do campo.
2. **[02-BLUEPRINT-SQUAD-INSTAGRAM.md](02-BLUEPRINT-SQUAD-INSTAGRAM.md)**: mande o link no chat do Maestro. Ele cria o canal, as skills e os agentes.
   > Leia e execute o blueprint deste link: https://raw.githubusercontent.com/dilandia/klaus-labs/main/squad-openbot-video-07/02-BLUEPRINT-SQUAD-INSTAGRAM.md
3. **[03-PRIMEIRO-POST.md](03-PRIMEIRO-POST.md)**: o guia para rodar o primeiro post no canal.
   Link: https://raw.githubusercontent.com/dilandia/klaus-labs/main/squad-openbot-video-07/03-PRIMEIRO-POST.md

Paperclip na Hostinger, do 1 clique ao time rodando

O template de 1 clique da Hostinger entrega o Paperclip com alguns detalhes faltando. Siga os passos na ordem: um comando arruma o servidor, dois ajustes arrumam o agente, e o seu CEO monta o time sozinho.

0 de 9
Antes de começar

Não reinicie, atualize nem reimplante a VPS pelo painel no meio do caminho. Isso recria o Paperclip e desfaz os passos 3 e 5. Se acontecer, rode os comandos dos passos 3 e 5 de novo, nessa ordem. O login do Claude não se perde.

Passo a passo

Marque cada passo ao terminar. O progresso fica salvo neste navegador.

  1. 1

    Instale o Paperclip pelo 1 clique

    Na Hostinger, contrate a VPS e escolha o aplicativo Paperclip na instalação de 1 clique. Espere o painel mostrar que está pronto.

    Ainda não tem VPS: link de indicação da Hostinger

  2. 2

    Abra o terminal da VPS

    No painel da Hostinger, abra o Terminal da VPS.

    Se a linha começar com node@, o terminal abriu dentro do Paperclip. Digite exit e aperte Enter. A linha tem que começar com root@.

  3. 3

    Cole o comando de preparação

    Ele acha o seu Paperclip sozinho, instala o Python (o login do Claude precisa dele) e corrige o endereço https (sem isso os Connectors não abrem). Leva uns 2 minutos.

    bash <<'EOF'
echo "== Parte 1: preparar o Paperclip (Hostinger 1 clique) =="
C=$(docker ps --format '{{.Names}}' | grep -E 'paperclip-[0-9]+$' | head -n1)
[ -z "$C" ] && { echo "ERRO: nao achei o container do Paperclip. Rode: docker ps"; exit 1; }
D=$(docker inspect "$C" --format '{{ index .Config.Labels "com.docker.compose.project.working_dir" }}')
F=$(docker inspect "$C" --format '{{ index .Config.Labels "com.docker.compose.project.config_files" }}')
P=$(docker inspect "$C" --format '{{ index .Config.Labels "com.docker.compose.project" }}')
S=$(docker inspect "$C" --format '{{ index .Config.Labels "com.docker.compose.service" }}')
DOM=$(docker inspect "$C" | grep -oE '[a-z0-9-]+(\.[a-z0-9-]+)*\.hstgr\.cloud' | awk '{print length, $0}' | sort -rn | head -n1 | cut -d' ' -f2)
[ -z "$DOM" ] && DOM="$P.$(hostname).hstgr.cloud"
URL="https://$DOM"
echo "Container: $C | Pasta: $D | Endereco: $URL"
echo "[1/3] Corrigindo o endereco https (para os Connectors funcionarem)..."
cat > "$D/docker-compose.override.yml" <<YML
services:
  $S:
    environment:
      PAPERCLIP_PUBLIC_URL: "$URL"
YML
ARGS=""; for f in $(echo "$F" | tr ',' ' '); do ARGS="$ARGS -f $f"; done
(cd "$D" && docker compose -p "$P" $ARGS -f "$D/docker-compose.override.yml" up -d) || { echo "ERRO ao recriar o container"; exit 1; }
sleep 8
C=$(docker ps --format '{{.Names}}' | grep -E 'paperclip-[0-9]+$' | head -n1)
echo "[2/3] Instalando Python 3 (necessario para o login do Claude)..."
docker exec -u root "$C" sh -c 'export DEBIAN_FRONTEND=noninteractive; apt-get update -qq && apt-get install -y -qq python3 >/dev/null; python3 --version'
NV=$(docker exec "$C" node -v 2>/dev/null); echo "Node: ${NV:-nao encontrado}"
NM=$(echo "$NV" | tr -d 'v' | cut -d. -f1); [ "${NM:-0}" -lt 20 ] 2>/dev/null && echo "ATENCAO: Node abaixo do 20. Nao continue; mande um print na comunidade."
echo "[3/3] Conferindo o endereco de retorno..."
sleep 10
curl -s "$URL/api/tools/oauth/client-metadata" | grep -o '"redirect_uris":\[[^]]*\]'
echo "== PARTE 1 PRONTA. Confira: Python 3.x, Node 20 ou maior e o endereco acima comecando com https. Agora faca o login do Claude no Paperclip. =="
EOF

    No final tem que aparecer: Python 3, Node 20 ou maior e um endereço começando com https.

    O comando reinicia o Paperclip. Se ele já estava aberto no navegador, atualize a página (F5) antes de continuar.

  4. 4

    Faça o onboarding até logar o Claude

    Abra o Paperclip pelo endereço https do painel. Crie a empresa, crie o agente CEO com o Claude Code e faça o sign-in do Claude (Subscription).

    Ainda não mande a missão. Antes, mais um comando e um teste.

  5. 5

    Só depois do login, atualize o Claude

    Volte ao terminal da VPS e cole este comando. A ordem importa: se o Claude for atualizado antes do login, o login trava em "Preparing browser sign-in".

    C=$(docker ps --format '{{.Names}}' | grep -E 'paperclip-[0-9]+$' | head -n1); echo "Container: $C"; docker exec -u root "$C" sh -c 'npm install -g --allow-scripts=@anthropic-ai/claude-code @anthropic-ai/claude-code@latest >/dev/null 2>&1; claude --version'

    No final tem que aparecer 2.1.3xx ou maior.

  6. 6

    Teste o CEO antes da missão

    No CEO, clique em Assign Task, título Teste, descrição Responda apenas: oi, estou funcionando. e clique em Run now.

    • Respondeu: está tudo certo. Siga para o passo 7.
    • Deu "Claude Code 2.1.257 does not support this model": vá em Agents › CEO › Harness / Runtime. Se aparecer o botão Upgrade runner, clique nele. Se aparecer o campo Execution engine, troque para Claude CLI. Salve e rode o teste de novo.

    Um erro "Paperclip Runner requires a standard, planning, or ask task" vindo de um run do tipo Timer é normal: o agente acordou sem tarefa. Pode ignorar.

  7. 7

    Dê as instruções de CEO

    Em Agents › CEO › Instructions, abra o AGENTS.md, clique em Edit, cole o texto abaixo e salve. Com o arquivo vazio, o CEO não sabe delegar.

    # CEO

Você é o CEO desta empresa. Você responde ao conselho (o humano dono da empresa) e lidera os outros agentes. Fale sempre em português do Brasil.

## Seu papel
- Você não executa o trabalho operacional. Você planeja, contrata, delega, acompanha e presta contas.
- Transforme cada objetivo da empresa em tarefas claras, com responsável, prazo e critério de pronto.
- Atribua cada tarefa ao agente certo pelo cargo dele. Se ninguém do time serve, proponha uma contratação.

## Contratações
- Antes de contratar, descreva o cargo, o que ele faz, as ferramentas que vai usar e por que é necessário.
- Só contrate depois da aprovação do conselho.

## A cada heartbeat
1. Veja se há aprovações pendentes e tarefas paradas ou com erro.
2. Destrave o que puder: responda dúvidas, ajuste instruções, redistribua tarefas.
3. Se um agente errar duas vezes na mesma tarefa, reescreva a instrução dele ou passe a tarefa para outro.
4. Escale para o conselho só o que você não consegue resolver: orçamento, decisão de estratégia ou falta de acesso.

## Regras
- Nunca invente dados, resultados ou fontes. Se não sabe, diga que não sabe.
- Não finja que uma etapa foi feita. Se uma ferramenta falhou, registre o erro na tarefa.
- Nada que envolva dinheiro, cliente real ou envio público sai sem aprovação, a menos que o conselho já tenha autorizado por escrito.
- Respeite o orçamento. Acima de 80% do mês, faça só o essencial e avise o conselho.

## Prestação de contas
Toda sexta, entregue ao conselho um resumo curto: o que foi feito, o que travou, quanto custou e o que vem na próxima semana.
  8. 8

    Mande a primeira missão

    No CEO, clique em Assign Task, título Montar a empresa IA do Dia, cole o texto abaixo na descrição e clique em Run now.

    Contexto: isto é uma demonstração para uma aula gravada. A empresa é fictícia, mas o trabalho é real: cada etapa precisa ser feita de verdade dentro do Paperclip. Não finja nenhuma etapa.

Você é o CEO da "IA do Dia", uma newsletter diária sobre inteligência artificial para donos de pequenos negócios. Sua missão é fazer a empresa rodar sozinha. Você não escreve nada: contrata, delega, cobra resultado e me presta contas.

Monte este time (proponha antes de contratar e espere minha aprovação):
1. Repórter: toda manhã pesquisa as novidades de IA das últimas 24h e entrega as 5 mais úteis para pequenos negócios, com link da fonte.
2. Redator: transforma a pauta em uma newsletter curta, em português simples, com uma dica prática no final.
3. Revisor: confere fatos, links e tom. Se algo estiver errado, devolve ao Redator com o motivo.
4. Publicador: publica a edição aprovada como um documento na tarefa do dia e atualiza o documento "Arquivo de edições" com a data e o título.

Como a empresa roda:
- Crie uma rotina diária às 7h que inicia o trabalho do Repórter. Cada agente passa a tarefa para o próximo.
- Toda sexta, me entregue um relatório: edições publicadas, problemas e o que vai melhorar.
- Se um agente travar ou errar duas vezes, ajuste a instrução dele ou redistribua a tarefa.

Regras:
- A primeira edição passa por mim antes de ser publicada. Depois, as próximas saem sem mim.
- Nunca invente notícia. Sem fonte, não entra.

Primeira entrega: organograma, descrição de cada cargo, a rotina configurada e o plano da primeira semana. Se faltar informação, faça até 3 perguntas antes.
  9. 9

    Aprove o time e veja a empresa andar

    • Responda as perguntas do CEO na própria tarefa.
    • Aprove as contratações no Inbox. Os 4 agentes aparecem no organograma.
    • Se algum agente novo der o erro 2.1.257, faça nele o ajuste do passo 6.
    • Em Routines, rode a rotina das 7h agora para não esperar até amanhã.
    • Aprove a primeira edição. Daí em diante ela sai sozinha todo dia.

Dúvida: o Node veio abaixo do 20

Só use se o passo 3 mostrar "ATENÇÃO: Node abaixo do 20". O Node é o que roda o próprio Paperclip, então não atualize sem precisar.

bash <<'EOF'
C=$(docker ps --format '{{.Names}}' | grep -E 'paperclip-[0-9]+$' | head -n1)
[ -z "$C" ] && { echo "ERRO: nao achei o container do Paperclip."; exit 1; }
W=$(docker exec "$C" sh -c 'command -v node')
echo "Container: $C | Node atual: $(docker exec "$C" node -v) em $W"
[ "$W" = "/usr/local/bin/node" ] || { echo "ERRO: o Node nao esta no lugar esperado. Nao atualize; mande um print na comunidade."; exit 1; }
T=$(curl -fsSL https://nodejs.org/dist/latest-v24.x/SHASUMS256.txt | grep -oE 'node-v[0-9.]+-linux-x64\.tar\.gz' | head -n1)
[ -z "$T" ] && { echo "ERRO: nao consegui achar o Node 24 no site oficial."; exit 1; }
echo "Baixando $T..."
curl -fsSL -o "/tmp/$T" "https://nodejs.org/dist/latest-v24.x/$T" || { echo "ERRO no download"; exit 1; }
docker cp "/tmp/$T" "$C:/tmp/node.tar.gz"
docker exec -u root "$C" tar -xzf /tmp/node.tar.gz -C /usr/local --strip-components=1 --exclude='*/CHANGELOG.md' --exclude='*/LICENSE' --exclude='*/README.md'
docker restart "$C" >/dev/null && sleep 10
echo "Node agora: $(docker exec "$C" node -v)"
echo "== Abra o Paperclip (F5). Se ele nao abrir, mande um print na comunidade. =="
EOF

Instala o Node 24 oficial dentro do Paperclip e reinicia ele (sem apagar nada). Se você atualizar ou reimplantar a VPS pelo painel, rode de novo junto com os passos 3 e 5.

Extra: conectar Gmail e Planilhas

Opcional, depois do time rodando. Graças ao endereço https do passo 3, os Connectors funcionam.

  1. A

    Conecte o Composio

    No Paperclip, abra Connectors, escolha Composio, clique em Connect Composio e autorize o Gmail e o Google Sheets quando ele pedir.

    No Google Drive, crie uma planilha chamada IA do Dia - Assinantes com duas abas: Assinantes (Nome, E-mail, Data de inscrição, Ativo) e Edições (Data, Título, Enviados, Status, Observações). Na aba Assinantes, coloque só e-mails seus para o teste.

  2. B

    Teste a planilha

    Crie uma tarefa para o agente com o título Teste de conexão com a planilha e esta descrição. Ele lê a planilha e escreve uma linha, sem enviar e-mail.

    Teste rápido da conexão com o Google Sheets pelo Composio. Não envie nenhum e-mail.

1. Encontre no Google Sheets a planilha "IA do Dia - Assinantes".
2. Leia a aba "Assinantes" e me diga quantas linhas de assinantes existem (não precisa listar os e-mails).
3. Na aba "Edições", acrescente uma linha nova com:
   Data: a data de hoje
   Título: TESTE de conexão
   Enviados: 0
   Status: teste
   Observações: linha criada pelo agente para testar a conexão
4. Leia a aba "Edições" de novo e confirme que a linha aparece.

Responda nesta tarefa com: o que encontrou, o número de assinantes, a confirmação da linha escrita e o link da planilha.

Se não encontrar a planilha ou alguma etapa falhar, não invente o resultado: diga exatamente em qual etapa parou e qual foi o erro.
  3. C

    Teste o envio de e-mail

    Título Teste de envio da newsletter. Este envia de verdade para quem está na aba Assinantes.

    Teste de envio por e-mail pelo Gmail (Composio). Isto é um teste da aula: envie de verdade, não simule.

1. Abra a planilha "IA do Dia - Assinantes" e leia a aba "Assinantes". Use só as linhas com "Ativo" = Sim e com um e-mail válido. Se encontrar algum e-mail com "TROQUE" no texto, pule esse e me avise.
2. Envie pelo Gmail um e-mail para cada assinante válido com:
   Assunto: IA do Dia - teste de envio
   Corpo: Olá, [nome]! Este é um e-mail de teste da IA do Dia, enviado automaticamente pelo time de agentes do Paperclip. Se você recebeu, a distribuição está funcionando.
3. Na aba "Edições", acrescente uma linha com:
   Data: a data de hoje
   Título: TESTE de envio
   Enviados: quantos e-mails saíram de fato
   Status: enviado (ou "falhou" se nenhum saiu)
   Observações: para quem foi e qualquer erro
4. Responda nesta tarefa: quantos e-mails saíram, para quem, e se algum falhou com o motivo.

Não envie para ninguém fora da aba "Assinantes". Se uma etapa falhar, não invente o resultado: diga em qual etapa parou e qual foi o erro.

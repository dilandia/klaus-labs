# Arquiteto de Agentes

Um agente que entrevista você sobre o seu negócio e monta outros agentes prontos para usar.

## Jeito mais rápido (OpenBot, Hermes, Claude Code)
Mande esta mensagem para o seu agente:

> Instale como skill o arquivo deste link: https://raw.githubusercontent.com/dilandia/klaus-labs/main/arquiteto-de-agentes/arquiteto-de-agentes/SKILL.md

## ChatGPT, Claude ou Gemini
Abra o prompt completo, copie o que está entre `=== INÍCIO ===` e `=== FIM ===`, cole numa conversa nova e escreva **oi**:
https://raw.githubusercontent.com/dilandia/klaus-labs/main/arquiteto-de-agentes/ARQUITETO-system-prompt.md

## Arquivos
- `ARQUITETO-system-prompt.md`: o prompt completo.
- `arquiteto-de-agentes/SKILL.md`: a skill (Claude Code, Hermes, OpenBot, Gemini).
- `versoes/`: passo a passo para ChatGPT, Claude, Gemini e a versão compacta.
- `Arquiteto-de-Agentes-Guia.pdf` e `Arquiteto-de-Agentes-Arquivos.zip`: o guia e o pacote para baixar.
